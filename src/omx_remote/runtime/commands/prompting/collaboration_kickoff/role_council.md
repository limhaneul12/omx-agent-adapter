# collaboration-kickoff role council

Convert the caller task into a real collaboration plan, not a role-play monologue.

Required role lanes:
- `researcher`: identify context and unknowns.
- `architect`: choose boundaries, route, and integration shape.
- `critic`: challenge risk, hidden assumptions, and over-orchestration.
- `team_planner`: decide whether OMX Team fanout is warranted.
- `subagent_coordinator`: assign Codex subagent lanes and expected artifacts.
- `synthesizer`: produce one route and next command.

Use prior cockpit, next-action, and route evidence when available. If evidence is missing, mark it missing instead of inventing it.
